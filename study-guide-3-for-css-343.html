Lectures 4 and 5 plus Homework 3, split into ten topics. Each topic is a short lesson, then its questions right away. Miss one and you'll see why your pick was wrong and how to get the right answer, and it comes back at the end of the topic. After all ten, a final check of 10 mixed questions. Score 9 or 10 and you're ready.

Tree shorthand used in some answers: 25(10, 50) means root 25, left child 10, right child 50. An underscore marks an empty spot, so 20(_, 30) is 20 with only a right child.

1. Vocabulary and height

  • Depth = links from the root (root 0). Height = deepest depth.
  • Leaf height 0, empty tree −1.
  • ⌊log₂ n⌋ ≤ height ≤ n − 1. Height h holds at most 2h+1 − 1.
  • full: 0 or 2 kids · perfect: full + all leaves on one level · complete: packed left · balanced: heights differ ≤ 1.
  • Perfect ⇒ complete ⇒ balanced, not backwards.
  • Every BST op is Θ(height).

2. Traversals

  • pre: node L R (root first) · in: L node R (BST sorted) · post: L R node (root last) · level: rows, queue.
  • Outline trick: pass left side = pre, under = in, right side = post.
  • Rebuild from pre + in: pre's first = root, split in-order around it, repeat.

3. Expression trees

  • Operators inside, numbers at leaves. Root = applied last = lowest precedence.
  • Evaluate in post-order: both children, then the operator.
  • pre → prefix, in → infix, post → postfix (RPN).
  • toInfix: "(" left op right ")" around every operator.
  • Left child first for − and ÷.

4. BST insert and in-order

  • The rule covers every key in each subtree, at every node.
  • Insert: search, hang new node at the null link. Equal key → update value.
  • First key = root. Sorted input → path (height n − 1).
  • In-order of any BST = sorted.
  • Compares = depth + 1. Random BST avg ~1.39 log₂ n, avg height ~2.99 log₂ n.

5. Floor, ceiling, ordered ops

  • Write the sorted list. floor(k) = at or just below k. ceiling(k) = at or just above. None → null.
  • Code: k > node → node is a candidate, look right; keep candidate if right finds nothing (floor(55) on the 10-key tree = 50).
  • rank(k) = # keys smaller. select(i) = key with rank i, 0-based. Inverses.
  • range(lo, hi) is inclusive. Cost height + output.
  • LCA: both smaller → left, both larger → right, else stop here.

6. Hibbard deletion

  • Leaf → remove. One child → splice the child up.
  • Two children → successor = right once, then left to the end. Copy it up, deleteMin it out.
  • Successor has no left child; its right child slides into its spot.
  • Predecessor = left once, then right to the end.
  • Always-successor → avg path ~√n.

7. Balance factors

  • bf = h(left) − h(right). Null = −1, leaf = 0.
  • Allowed −1, 0, +1. ±2 → rotate.
  • Check every node. A fine root proves nothing.
  • Only the insert/delete path can change.
  • isAVL: return heights from the recursion, linear.

8. Rotations

  • Right at y: left child x rises, y drops right, x's right subtree moves to y's left.
  • Left is the mirror.
  • Only the middle subtree changes parent. In-order unchanged.
  • O(1). Fix the lower node's height first.

9. AVL insertion cases

  • Fix the lowest ±2 node.
  • Same signs (LL / RR) → one rotation toward the light side.
  • Opposite signs (LR / RL) → rotate the child first, then the node.
  • Double shortcut: middle key of the three goes on top.
  • Insert: ≤ 1 rotation. Delete: up to one per level.
  • 1…7 in order → 4(2(1,3),6(5,7)).

10. Height bound

  • N(h) = 1 + N(h−1) + N(h−2).
  • 1, 2, 4, 7, 12, 20, 33, 54, 88, 143.
  • N(h) + 1 is Fibonacci.
  • Max height with n nodes = largest h with N(h) ≤ n.
  • log₂ n ≤ h ≤ 1.44 log₂ n. 10⁹ keys → ≤ 43.
  • Red-black ≤ 2 log₂ n, fewer rotations.
